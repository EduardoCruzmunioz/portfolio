## El Proyecto

Este proyecto es la culminación práctica de conceptos avanzados de **Programación Orientada a Objetos en Java** (correspondiente al Tema 9 del módulo de Programación).

Mientras que los primeros temas asientan las bases de la sintaxis, este proyecto demuestra un dominio más profundo de la arquitectura de software en Java.

---

## Conceptos Aplicados

- **Herencia y Polimorfismo:** Diseño de jerarquías de clases eficientes y escalables, evitando la duplicidad de código.
- **Colecciones Avanzadas:** Uso de estructuras de datos nativas de Java (Listas, Mapas, Sets) para la manipulación y búsqueda eficiente de información.
- **Manejo de Excepciones:** Código seguro y a prueba de fallos, capturando y tratando los errores para evitar cierres inesperados de la aplicación.
- **Encapsulamiento y Buenas Prácticas:** Código limpio, modular y fácilmente mantenible.

## Lo que demuestra

Más allá de saber escribir código, este repositorio refleja mi capacidad para **pensar de forma abstracta** y estructurar programas como lo haría un desarrollador Backend profesional, sentando las bases para futuros proyectos con frameworks como Spring.
