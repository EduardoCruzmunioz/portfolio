## Sobre el Proyecto

**FernanPop** es un sistema de plataforma de compraventa y mercado de productos. Está construido íntegramente en **Java**, aplicando una arquitectura sólida para separar la lógica de negocio, el acceso a los datos y la gestión de usuarios.

---

## Funcionalidades Principales

- **Gestión de Artículos:** Sistema completo para publicar, modificar y listar productos con sus respectivos atributos y precios.
- **Perfiles de Usuario:** Módulo para la gestión de identidades de los participantes en la plataforma.
- **Flujo de Transacciones:** Lógica centralizada para gestionar los estados de los artículos y simular el ciclo de compraventa.

## Lo que demuestra

Este desarrollo es una demostración clara de cómo estructurar una aplicación orientada a producto utilizando principios avanzados de **Programación Orientada a Objetos**. Refleja mi capacidad para diseñar reglas de negocio complejas y construir software preparado para escalar y manejar datos relacionales.
