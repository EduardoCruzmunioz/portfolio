## Sobre el Proyecto

**Bored Activity App** es una aplicación web que resuelve un problema cotidiano: no saber qué hacer. Conecta con una API pública para devolver actividades aleatorias al usuario, permitiéndole filtrar por tipo de actividad o número de participantes.

---

## Funcionalidades Principales

- **Sugerencias Aleatorias:** Consulta en tiempo real una API REST externa para obtener actividades variadas (deporte, educación, cocina, entretenimiento, etc.).
- **Filtrado por Parámetros:** El usuario puede ajustar el tipo de actividad o el número de participantes para personalizar los resultados.
- **Interfaz Reactiva:** La UI se actualiza de forma instantánea ante cada nueva solicitud sin recargar la página.

## Lo que demuestra

Este proyecto evidencia el dominio del ciclo completo de consumo de APIs REST desde el navegador: gestión de peticiones asíncronas, manejo de respuestas JSON y renderizado dinámico del resultado en la interfaz. Desarrollado íntegramente en **TypeScript**, refleja el uso de tipado estático para garantizar la fiabilidad del código en proyectos frontend.
